# Scope

This repository contains a limited, self-funded Fist Commerce feasibility prototype created before the SCF submission. It is not a production lending protocol, has not completed a production security review, uses synthetic Testnet data and holds no real merchant or investor capital. SCF funding is not requested retroactively for this prototype.

## Track B expansion (honesty note)

In addition to the brief’s AttestationRegistry + TradeCreditPool submission surface, this repo includes Track B modules (allocator, payout router, protocol pauses, receivable token, multisig), a GraphQL event indexer, and capability-gated Fist Commerce frontend wiring for Soroban Testnet. That work is expanded self-funded feasibility beyond the minimal pre-submission brief and must not be described as production-complete or as retroactive SCF delivery.
